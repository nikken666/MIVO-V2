# MIVO V2 Black & Red

## Upload your own logo
Replace this file in `public`:

- `public/mivo-logo.png`

Keep the same filename. Recommended transparent PNG size: about 600 × 180 px.

## MIVO mascot/IP
The homepage uses:

- `public/mivo-ip.png`

You may replace it with another transparent/full-body mascot PNG using the same filename.

## Run

```bash
npm install
npm run dev
```

## Build check

```bash
npm run build
```

Then commit and push to `main`; Vercel will redeploy automatically.
